# REVERIUS OPIUM Diagnostics

## Commands

- `reverius doctor` runs the built-in diagnostic pass and generates a report.
- `reverius repair` performs safe repair actions and refreshes health artifacts.
- `reverius troubleshoot` gathers a lightweight troubleshooting report.
- `reverius benchmark` produces a benchmark snapshot for startup, memory, and plugin load time.

## Outputs

- project_health.json
- project_health.md
- project_health.html
