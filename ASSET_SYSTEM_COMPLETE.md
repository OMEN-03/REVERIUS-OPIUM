## 💻 How to Use the Asset System

### Python Integration

```python
from utils.asset_manager import AssetManager

# Load logos
logo = AssetManager.logo("reverius_opium_main_logo.png")

# Load icons with color variants
icon_gold = AssetManager.icon("icon_gold.png")
icon_neon_blue = AssetManager.icon("icon_neon_blue.png")

# Load wallpapers
wallpaper = AssetManager.wallpaper("wallpaper_core_golden.png")

# Other asset types
font = AssetManager.font("Consolas.ttf")
sound = AssetManager.sound("startup.wav")
model = AssetManager.model("ai_model.onnx")
```

## 🔧 Technical Specifications

### AssetManager API

```python
class AssetManager:
    # Main methods
    .image(name)          # General image
    .icon(name)           # UI icon
    .logo(name)           # Logo/branding
    .wallpaper(name)      # Wallpaper/background
    .sound(name)          # Audio asset
    .font(name)           # Font file
    .model(name)          # AI/ML model
    .prompt(name)         # Prompt template
    .config(name)         # Configuration
    .data(name)           # Data file
    .doc(name)            # Documentation
    .template(name)       # Template file
    .theme(name)          # Theme file
    
    # Utility methods
    .resolve(path, category)  # Custom path resolution
    .ensure_exists(path)       # Create path if needed
```

### File Organization Standard

```
assets/{category}/{subcategory}/{asset_name}.{ext}

Examples:
- assets/images/icons/color_palette/icon_gold.png
- assets/images/wallpapers/wallpaper_core_golden.png
- assets/audio/notifications/alert.mp3
- assets/models/ai_assistant.onnx
```
